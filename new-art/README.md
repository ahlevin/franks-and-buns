Six original PNG assets made with the built-in image generator, using chef.png and dog.png as style references and the first wall as the shared environment reference.

- back-wall-b.png: 1536 × 1024 px

The built-in generator returned these native sizes despite requests for larger output. No artificial upscaling has been applied. Horizontal tiling was requested, but the scrolling images are not guaranteed pixel-perfect seamless; light seam blending may be needed. Assets contain no characters or menu text.

Open preview.html for side-by-side comparisons and repeating-strip checks.
